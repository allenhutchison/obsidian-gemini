### [#1819 Make eval tests pass on Windows](https://github.com/allenhutchison/obsidian-gemini/pull/1819)

Test-only fix for issue #1818: four eval tests failed on Windows because of assumptions in the tests themselves. The `getBaselinePath` tests in `test/evals/compare.test.ts` now build expected paths with `path.join`, and the path-traversal check gains a backslash case. The SIGKILL-escalation test in `spawn-with-timeout.test.ts` is skipped on Windows, where `SIGTERM` can't be ignored. Linux behaviour is unchanged.

Contributed by @doherty.

### [#1816 Load a pinned session provider's models even when no feature uses it](https://github.com/allenhutchison/obsidian-gemini/pull/1816)

Fixes the 4.15.0 release blocker from smoke step 2.3. If you pinned a session to a provider that no feature routes to and left Model on "Use default", Send failed with "No chat model is selected", because the global model list only held models for routed providers. The same gap sent a Claude model id to Gemini's `countTokens` (a 404) and showed the wrong context window for a session pinned to GPT-6.2. `ModelManager` now also loads every connected chat provider, skipping an Ollama daemon nobody has probed. A new `ensureProviderModels(provider)` runs before a send, before token counting, and in the session settings modal. Stale-model reconciliation still covers only the active providers.

### [#1820 Fix two agent-turn-ended hook bugs](https://github.com/allenhutchison/obsidian-gemini/pull/1820)

Two fixes to the trigger from #1812 (issue #1817). First, a turn ended by "Stop the agent when a tool fails" reported `turnOutcome` = `complete`. It now reports `failed`, via a new `toolFailedStop` flag on `AgentLoopResult`. Second, `{fileName}` in an agent-turn hook's `outputPath` resolved to an empty name, so every run wrote to the same hidden `.md` dotfile. That placeholder is now refused for this trigger: on create and update, when a hand-written hook loads, and in the hook editor, which also shows trigger-specific help text. The lifecycle hooks guide is updated.

Contributed by @doherty.

### [#1827 Keep hook and scheduled-task usage out of the chat's token counter](https://github.com/allenhutchison/obsidian-gemini/pull/1827)

Fixes issue #1823, found in smoke steps 1.6 and 1.9. Headless agent turns (hooks and scheduled tasks) shared the chat's `ContextManager`. Their usage updated the chat's token footer and recalibrated its chars-per-token estimate, and their mid-loop compaction ran against the chat's cached usage. `runHeadlessAgentTurn` now creates its own `ContextManager` per run and passes it to `AgentLoop` through a new `contextManager` option. `apiResponseReceived` events from these runs carry `headless: true`, which `ContextTrackingSubscriber` ignores.

### [#1829 Show one Rescan complete notice when the sync queue overlaps a rescan](https://github.com/allenhutchison/obsidian-gemini/pull/1829)

Fixes issue #1825, from smoke step 8.1. When the background sync queue flushed during a vault rescan, it flipped the shared index status to `idle` partway through the scan. `RagProgressModal` treated each later event as a new completion, so the smoke run saw about 80 "Rescan complete" notices. The sync queue now holds its changes while a scan is active and leaves the status alone, and the modal's completion handler runs only once. The other half of 8.1, no live progress during the change-detection phase, is tracked in #1826 and is not covered here.

### [#1828 Report a Stop on an Allow card as cancelled, not a tool failure](https://github.com/allenhutchison/obsidian-gemini/pull/1828)

Fixes issue #1824, from smoke step 3.2. Pressing Stop while an Allow/Cancel card was showing declined the confirmation. `AgentLoop` then ran its tool-error checks before its cancellation check, so the turn ended with "The agent stopped because a tool call failed". The loop now checks for cancellation first and returns a plain cancel, keeping the batch's call/response turns in history. Declining a confirmation without pressing Stop still stops on tool error, as before. With #1820 merged, the hook sees such a turn as `cancelled`.
