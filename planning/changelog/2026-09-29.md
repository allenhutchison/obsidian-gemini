### [#1617 refactor(anthropic): hold the model list in the shared CachedModelCatalog (#1612)](https://github.com/allenhutchison/obsidian-gemini/pull/1617)

`AnthropicModelsService` carried its own copy of the model-list caching logic, without the generation guard that `CachedModelCatalog` has. A fetch still running when `invalidate()` ran could write the old key's list back into the cache. The service now holds a `CachedModelCatalog`, like the OpenAI and Ollama services, and the catalog gained an optional `fallback` list (the curated Anthropic models). No user-visible change beyond the race fix; four regression tests were added.

### [#1616 fix(anthropic): drop stale thinking blocks instead of failing mid-chain compaction (#1608)](https://github.com/allenhutchison/obsidian-gemini/pull/1616)

Compaction partway through an Anthropic tool chain rewrote the history that replayed thinking-block signatures are bound to, so newer accounts got a 400 on the follow-up request. Adaptive-thinking requests now send `thinking.block_binding.prefix_mismatch_behavior: 'drop_block'` with the `thinking-binding-controls-2026-08-01` beta, so the API drops only the stale blocks and the chain continues. Dropped blocks are logged at debug level. The known-limitation entries were removed from `anthropic-setup.md` and `provider-capabilities.md`. Not yet verified live; the PR describes a 5% compaction-threshold check.
