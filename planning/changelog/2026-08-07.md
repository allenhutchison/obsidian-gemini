### [#1319 refactor(rag): drop two unread status getters, bind getDetailedStatus to its type](https://github.com/allenhutchison/obsidian-gemini/pull/1319)

Filed by the `audit-architecture` sweep. `RagIndexingService.getStatusInfo()` and `getPendingCount()` had no callers outside their own tests — `getDetailedStatus()` already returns a strict superset of the same data and is what `RagStatusProvider` actually uses. Both dead methods (and the tests that existed only to cover them) were removed, and `getDetailedStatus()`'s inline anonymous return type was replaced with the named `RagDetailedStatus` type so future fields on that type can't silently drift out of sync with the implementation. No behavior change.

### [#1320 refactor(providers): inline the pass-through buildSystemInstruction wrapper](https://github.com/allenhutchison/obsidian-gemini/pull/1320)

Also filed by the `audit-architecture` sweep. The OpenAI and Ollama clients each carried a byte-identical private `buildSystemInstruction()` wrapper that did nothing but forward to `this.prompts.buildExtendedSystemInstruction()`, with no provider-specific behavior behind it and no Gemini-client equivalent. Both call sites now call the prompts method directly. No behavior change.
