### [#1786 fix(ollama): send ollama.com requests through requestUrl so Ollama Cloud chat works](https://github.com/allenhutchison/obsidian-gemini/pull/1786)

Every chat with a model served directly by ollama.com failed with `Failed to fetch`. ollama.com sends no CORS headers, so Chromium blocked the renderer's `fetch`. The Ollama client now builds the ollama.com SDK client with the existing `requestUrl`-backed `proxyFetch` adapter. Local and custom endpoints keep `window.fetch` and still stream. This fixes both the `cloud::` entries in the mixed model list and the cloud-only `https://ollama.com` endpoint (#1785).

This has a cost: `requestUrl` buffers the response, so direct-cloud replies arrive all at once when generation finishes. Stop settles the turn, but ollama.com keeps generating because the request can't be aborted. A new transport test drives the real ollama-js client with only `requestUrl` faked.

### [#1789 4.14.0 pre-tag cleanup: Ollama Cloud note and plugin-scan fixes](https://github.com/allenhutchison/obsidian-gemini/pull/1789)

The last change before tagging 4.14.0. The README and `src/release-notes.json` now say that replies from direct-cloud Ollama models don't stream. Two dependency advisories were cleared: the `ip-address` override goes to `^10.7.6` and `body-parser` goes to 2.4.0. Both reach the project only through `@modelcontextprotocol/sdk`'s server-side dependencies and are not bundled. `npm audit --omit=dev` now reports 0 vulnerabilities. The Ollama client's `drain()` was also rewritten to remove an unused loop binding that the scan flagged, with no change in behaviour.

### [#1792 Fix the Stop race, error-message classification and Ollama Stop leak (4.14 follow-ups)](https://github.com/allenhutchison/obsidian-gemini/pull/1792)

The first batch of 4.14 follow-ups, closing eight issues:

- **Stop race (#1787, #1790, #1780).** Each agent turn now gets its own `ActiveTurn` token. A turn resets the Stop button only while it still owns the button, so a late follow-up from a stopped turn can't clear the next turn's Stop target. Stop, or sending a new message, now marks pending tool-permission cards as cancelled, so an Allow card can't outlive its turn.
- **Error classification (#1719).** A shared `getComparableErrorText` helper means the rate-limit and quota checks accept bare error strings too. For example, a 429 in a persisted `lastError` string now counts as a rate limit.
- **Ollama errors (#1791, #1788).** A missing Ollama Cloud key now shows the plugin's own message instead of the generic "Invalid API key" text. Aborted Ollama streams are now removed from the SDK's in-flight list.
- **Docs and tests (#1781, #1721).** The `apiKeySecretName` default and the initial feature routes are now in the settings docs. New tests pin the bundled-frontmatter parser's contract.

Desktop testing was still pending when it merged.
