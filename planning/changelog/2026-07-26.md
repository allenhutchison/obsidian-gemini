## What shipped

### [#1257 fix(mobile): remove regex lookbehind that crashes plugin load on iOS < 16.4](https://github.com/allenhutchison/obsidian-gemini/pull/1257)

`manifest.json` sets `isDesktopOnly: false`, so the plugin loads on mobile, but five regex literals across two files used negative lookbehind (`(?<!...)`), which is only supported on iOS 16.4+. On older iOS, an unsupported lookbehind literal is a parse-time `SyntaxError` that aborts the whole bundle — so this crashed plugin _load_, not just the affected feature. The fix rewrites all five (one backtick-wrapped-wikilink pattern in `src/utils/markdown-formatting.ts`, and four small-model size-hint patterns in `src/services/ollama-models-service.ts`) to lookbehind-free consuming-group forms, keeping the lookaheads (which Safari has long supported). A new source-scan guard test (`test/utils/no-regex-lookbehind.test.ts`) fails the build if any lookbehind literal reappears under `src/`.
