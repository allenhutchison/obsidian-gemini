## What shipped

### [#1731 Name generated images after their actual format](https://github.com/allenhutchison/obsidian-gemini/pull/1731)

Generated images were always saved with a `.png` name even when Gemini image models returned JPEG, which broke tools that check magic bytes against the extension. `saveImageToVault` now sniffs the decoded bytes (JPEG, PNG, WebP, GIF) and picks the extension to match; unrecognised bytes keep `.png`. In background mode the promised path is now provisional, and the tool text tells the agent to try `.jpg`/`.webp`/`.gif` if the `.png` is missing.

The PR also lets `read_file` open files under `[state-folder]/Background-Tasks/` by exact path, so the agent can read back generated images and deep-research reports. The rest of the state folder stays blocked.

### [#1736 Add OpenRouter as a first-class provider](https://github.com/allenhutchison/obsidian-gemini/pull/1736)

Adds `openrouter` to the provider registry with its own settings card, API key and model catalog, built as a thin subclass of the OpenAI client. Pointing the OpenAI card at OpenRouter already handled plain chat, but image generation used the wrong endpoint, `reasoning_details` were dropped across tool rounds, model metadata was ignored, and OpenAI and OpenRouter could not be used side by side.

The shared OpenAI client now also reads OpenRouter's `reasoning` text and replays `reasoning_details` through the first tool call's `thoughtSignature`. A new models service reads the live catalog for labels, context windows and role defaults. Includes a new `docs/guide/openrouter-setup.md` and updates to the capability matrix, settings reference and README. Not yet run in a live vault.

### [#1737 Surface silent session-history failures](https://github.com/allenhutchison/obsidian-gemini/pull/1737)

Two configurations lose every agent session without an error: "Keep session history" turned off (the default) and a plugin folder whose name starts with a dot, which Obsidian does not index. The Plugin folder setting now rejects dot-prefixed segments with an inline error, and a persisted bad value logs a warning. The agent view empty state and Browse sessions now say when history is off. Fixes #1730.
