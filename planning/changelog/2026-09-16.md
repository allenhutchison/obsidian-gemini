### [#1532 feat: add Anthropic (Claude) as a model provider](https://github.com/allenhutchison/obsidian-gemini/pull/1532)

Fixes #1524. Adds `AnthropicClient` on the official `@anthropic-ai/sdk`, wired through the same provider layer as Gemini, Ollama, and OpenAI — streaming and non-streaming chat, tool calling, image and PDF attachments, automatic prompt caching, adaptive thinking rendered in the agent view, and a server-side refusal fallback on Opus 5/Fable 5.1. Anthropic can now serve Chat/agent, Summaries, Completions, and Rewrite from the Features page (web search, deep research, vault search, image generation, and maps stay Gemini-only). The Anthropic settings card, previously a placeholder that collected an unused key, becomes a real provider card, and every provider's model dropdown now names the resolved model in its "Default" label. Ships with a new `docs/guide/anthropic-setup.md` guide plus updates across the FAQ, getting-started, settings reference, and provider-capabilities docs.

A known limitation is called out as a follow-up: if context compaction fires mid tool-chain, Anthropic's history-editing check can reject the replayed thinking blocks with a 400 near the compaction threshold.
