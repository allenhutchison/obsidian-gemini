### [#1665 fix: Separate session and selection prompts and explain the tag](https://github.com/allenhutchison/obsidian-gemini/pull/1665)

Prompts created via "Create new custom prompt" never appeared in the right-click "Apply prompt..." picker because it only lists prompts tagged `gemini-scribe/selection-prompt`, and nothing explained that. The new-prompt template now describes the tag, the picker shows a footer hint when untagged vault prompts exist, and the session "Prompt template" dropdown excludes selection-tagged prompts so the tag separates the two kinds in both directions. Fixes #1663.

The session dropdown also previously read only the Prompts folder's direct children; it now includes subfolders, labelled by relative path. User guides (`custom-prompts.md`, `selection-prompts.md`) and the README were updated. Making bundled prompts readable or editable in the vault is a separate, unaddressed request from the same report.
