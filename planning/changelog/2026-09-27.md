### [#1601 fix(mcp): explain OAuth errors that return an HTML page (#1597)](https://github.com/allenhutchison/obsidian-gemini/pull/1601)

Fixes #1597: connecting to a hosted MCP server whose firewall rejects the loopback OAuth callback surfaced a raw `Invalid OAuth error response` parse error, and the agent misdiagnosed it as a missing Streamable HTTP feature. Adds `explainMCPConnectionError()` to turn that specific SDK error shape into a plain-language explanation, and fixes the stale "HTTP uses SSE" doc line that caused the agent's wrong diagnosis, plus documents the loopback callback requirement.

### [#1602 chore(i18n): Update UI translations](https://github.com/allenhutchison/obsidian-gemini/pull/1602)

Automated translation regeneration from `src/i18n/en.ts`; only keys whose English source changed were retranslated.

### [#1603 fix(gemini): carry thought signature to tool calls in non-streaming Interactions responses](https://github.com/allenhutchison/obsidian-gemini/pull/1603)

Release blocker found in the 4.12.0 pre-release test: every scheduled task or `agent-task` hook that called a tool failed its first follow-up with a `400 Request contains an invalid argument` from Gemini. The non-streaming Interactions path read the thought signature off the wrong response step; it's now carried over from the preceding `thought` step to the next `function_call`, matching the streaming path's existing behavior. Regressed when #1508 made the Interactions API unconditional.

### [#1604 fix: polish findings from the 4.12.0 pre-release test run](https://github.com/allenhutchison/obsidian-gemini/pull/1604)

Four non-blocking fixes from the same test run: settings no longer probes providers the user hasn't configured a key for; model-override placeholders show the resolved chat model instead of a hard-coded `gemini-2.0-flash`; headless scheduled-task/hook runs no longer log a spurious missing-history-file warning; and tool-registry debug logs show tool names instead of minified class names.

### [#1605 docs: fix doc gaps from the 4.12.0 pre-release test run](https://github.com/allenhutchison/obsidian-gemini/pull/1605)

Fixes 13 doc gaps found in the same test run — session deletion, permissions, `generate_image` routing, loop-detection thresholds, renamed settings labels, RAG indexing defaults, a new "After an Update" section, and a rewrite of `completions.md` to remove false "smart context extraction" claims — plus test-harness fixes to the `plugin-test` and `obsidian-cli` skills that the run surfaced.

### [#1607 fix(projects): make Switch project open the picker and ask Create project for a name](https://github.com/allenhutchison/obsidian-gemini/pull/1607)

Two project-command bugs from the pre-release test run: **Switch project** now opens the project picker as documented instead of just the agent view, and **Create project** now prompts for a name (pre-filled "New Project") instead of silently writing `New Project.md` and failing on a repeat run in the same folder.

### [#1609 docs: refresh release smoke gate and document Anthropic compaction limitation](https://github.com/allenhutchison/obsidian-gemini/pull/1609)

Follow-ups from the 4.12.0 release: the release smoke-test guideline no longer tells reviewers to flip a since-removed Interactions API toggle, and now covers three concrete smoke checks (summary, streamed agent chat, a grounded `google_search` call with a streamed tool follow-up). Also documents a known Anthropic mid-chain compaction limitation (#1608) in the Anthropic setup guide and provider capability reference, to be removed once #1608 is fixed.
